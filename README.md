# 📂 The Senior Folder

> *The unofficial stash of everything seniors wish they had when they were juniors.*

Hi, I’m **<NAME>**, and I’m currently the sole maintainer of this senior folder.

I’m not entirely sure how you found your way here — perhaps a senior passed it down to you, perhaps a friend sent you the link, or perhaps you simply stumbled upon it.

Either way, welcome.

This repository is a collection of undergraduate course materials shared by seniors, with the hope that they’ll be useful to juniors studying **Statistical Data Science / Actuarial Science** in MACS.

Notes, slides, past materials, references, tips, and whatever else might help someone survive a course are welcome here.

## 🫡 But there's a problem...

There comes a point where a repository like this gets **overwhelming to maintain**.

Files pile up. Links break. Courses change. New cohorts come and go. Eventually, one person can't realistically keep track of everything — and **that point will come**.

So, if this repository has helped you in any way, I’m asking you to **pay it forward as a MACS student**.

You don't have to become a full-time maintainer. Even small contributions help:

- 📚 **Add** useful course materials that you have.
- 🗂️ **Organise** or rename files when things get messy.
- 🧹 **Flag** outdated, duplicated, or incorrect materials.
- 🔗 **Fix** broken links.
- 📝 **Share** useful resources, tips, or notes for courses you've taken.
- 🤝 **Pass this repository on** to juniors who might benefit from it.

The idea is simple:

> **You benefit from what seniors left behind, and you leave something behind for the people after you.**

## 🔀 Contributing

This repository is maintained through **GitHub pull requests**.

If you have something useful to contribute:

1. Fork the repository.
2. Add or update the relevant materials.
3. Keep files organised and use sensible names.
4. Open a pull request explaining what you added or changed.
5. Someone will review it and merge it into the repository.

You don't need to ask for permission before preparing a contribution. If you think something would make the repository more useful, **give it a shot**.

### A few guidelines

- Don't upload materials that you are not allowed to redistribute.
- Avoid uploading personal information or private communications.
- Don't delete existing materials unless there is a good reason.
- Avoid unnecessary duplication.
- Keep the existing folder structure intact where possible.
- If you're unsure where something belongs, open a PR anyway — we can figure it out together.

## 🧹 Keeping things alive

This repository will inevitably become messy if nobody looks after it.

If you notice something that could be improved, **don't just think "someone should fix this."**

You might be that someone.

Even a small pull request helps make this resource better for the next cohort.

## 🔐 One last thing

This isn't really *my* folder.

I'm just the person currently holding the keys.

The whole point is for this to outlive any one maintainer, cohort, or batch of students. Hopefully, when your juniors eventually stumble across this repository, they'll find something useful here — just as you did.

**Thanks for keeping the chain going. ❤️**
